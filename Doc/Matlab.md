## 最小运行练习

将下面代码保存为脚本并运行，确认变量、数组运算和绘图流程都能正常工作：

```matlab
clear; clc; close all;

Fs = 1000;
t = (0:999) / Fs;
x = sin(2*pi*5*t) + 0.1*cos(2*pi*40*t);

figure;
plot(t, x);
grid on;
xlabel('Time (s)');
ylabel('Amplitude');
title('Sample signal');
```

练习要求：
1. 把 5 Hz 与 40 Hz 改成其他频率，观察波形变化。
2. 修改采样率和采样点数，确认时间轴与数据长度一致。
3. 使用 `mean`、`max`、`min` 计算统计量。
4. 为脚本添加输入参数检查，并把信号生成逻辑改写成函数。
