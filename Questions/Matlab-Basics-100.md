# MATLAB 基础 100 问

> 面向系统学习、面试复习和工程实践。建议先独立回答，再运行示例验证。示例以 MATLAB 基础语法为主；个别函数的可用性可能受版本或工具箱影响。

## 使用方法

- 每次学习 5～10 问：先口述概念，再手写代码，最后记录一个边界条件。
- 不要只背语法：至少运行示例，并修改输入观察结果。
- 工程代码要关注尺寸、数据类型、异常输入、数值精度和可复现性。

## 一、环境与基本概念（1–10）

### 1. MATLAB 主要用于什么？
用于数值计算、矩阵运算、数据分析、可视化、算法原型验证，以及通过工具箱和 Simulink 扩展工程应用。

### 2. Command Window、Workspace、Current Folder 分别做什么？
Command Window 执行命令；Workspace 查看当前变量；Current Folder 管理当前目录中的文件。脚本依赖的文件应放在可控路径中。

### 3. 如何查询函数帮助？
```matlab
help mean
doc mean
which mean -all
```
`help` 查看命令行说明，`doc` 打开文档，`which -all` 检查函数实际来自哪里。

### 4. 如何查看版本与安装信息？
```matlab
version
ver
computer
```
提交项目时应记录 MATLAB 版本及依赖工具箱。

### 5. 脚本和函数有什么区别？
脚本在当前工作区运行；函数拥有独立工作区，通过输入参数和输出参数交互。可复用、可测试的逻辑优先写成函数。

### 6. 分号有什么作用？
行尾分号抑制命令窗口输出，不会改变计算结果。调试时可临时去掉分号观察中间值。

### 7. `clear`、`clc`、`close all` 有何区别？
`clear` 清除工作区变量；`clc` 清屏；`close all` 关闭图窗。它们互不等价。

### 8. 如何设置当前目录与搜索路径？
使用 Current Folder 工具栏，或通过 `cd`、`pwd`、`addpath`、`rmpath` 管理。不要依赖个人电脑上的硬编码绝对路径。

### 9. MATLAB 区分大小写吗？
变量名和函数名通常区分大小写；`data` 与 `Data` 是不同变量。文件名与平台文件系统也可能影响函数解析。

### 10. 如何让实验可复现？
固定随机种子、保存输入数据和参数、记录软件版本，并提供一条明确的运行入口：
```matlab
rng(1);
```

## 二、变量、数据类型与数组（11–20）

### 11. 如何创建变量？
```matlab
temperature = 25.0;
name = "sensor_A";
enabled = true;
```
变量由赋值创建；避免使用 `i`、`j` 作为普通变量名，以免遮蔽虚数单位。

### 12. 如何查看变量类型和尺寸？
```matlab
class(temperature)
size(temperature)
numel(temperature)
whos
```

### 13. 行向量和列向量如何创建？
```matlab
row = [1 2 3];
col = [1; 2; 3];
col2 = row.';
```
点转置 `.'` 不做复共轭；`'` 对复数会做共轭转置。

### 14. 冒号表达式如何工作？
```matlab
x = 0:0.1:1;
k = 10:-2:2;
```
格式是起点:步长:终点；浮点步长可能出现舍入误差，不要假设元素个数总能由十进制直觉精确确定。

### 15. `linspace` 与冒号有什么区别？
`linspace(a,b,n)` 生成 n 个等间距点并包含端点（n 合法时）；冒号表达式指定步长。需要固定采样点数时常用 `linspace`。

### 16. 如何创建全零、全一和单位矩阵？
```matlab
Z = zeros(3,4);
O = ones(2,3);
I = eye(3);
R = rand(3,2);
```

### 17. MATLAB 常见数据类型有哪些？
常见有 `double`、`single`、整数类型、`logical`、字符/字符串、cell、struct、table、categorical 和 datetime。应根据精度、内存和接口需求选择。

### 18. 字符向量和 string 有什么区别？
```matlab
a = 'sensor';
b = "sensor";
```
二者是不同类型。处理文本时注意函数对字符向量、字符串数组的输入要求及版本差异。

### 19. 如何处理缺失或无效数值？
`NaN` 表示非数值，`isnan` 检查 NaN，`isfinite` 检查有限值。缺失值策略要依据业务含义决定，不能随意替换成零。

### 20. 浮点数为什么不适合直接比较相等？
二进制浮点数无法精确表示许多十进制小数。比较计算结果时可按量纲和误差预算使用容差：
```matlab
isClose = abs(a-b) <= 1e-9;
```

## 三、索引与矩阵运算（21–30）

### 21. MATLAB 索引从几开始？
从 1 开始。访问越界索引会报错（部分赋值场景可能扩展数组），因此应检查索引范围。

### 22. 如何访问矩阵元素？
```matlab
A = [1 2 3; 4 5 6];
x = A(2,3);   % 6
r = A(2,:);
c = A(:,1);
```

### 23. 线性索引是什么？
MATLAB 按列优先存储和线性索引：
```matlab
A = [10 20; 30 40];
A(2) % 30
```
线性索引不等于按行阅读的顺序。

### 24. 如何删除数组元素或整行？
```matlab
A(:,2) = [];
A(1,:) = [];
```
删除后尺寸会变化；若需要保持固定尺寸，应考虑掩码或预分配替代方案。

### 25. `A*B` 和 `A.*B` 有什么区别？
`*` 是矩阵乘法，要求内维度匹配；`.*` 是逐元素乘法，数组尺寸需相同或满足隐式扩展规则。

### 26. `^` 和 `.^` 有什么区别？
`A^n` 表示矩阵幂（对方阵定义）；`A.^n` 对每个元素分别取幂。

### 27. 左除与右除分别是什么？
`A\b` 求解线性系统 A*x=b；`b/A` 对应右除问题。数值计算中，求解线性方程通常优先使用 `A\b`，不要轻易写 `inv(A)*b`。

### 28. 为什么通常不建议显式求逆？
`A\b` 通常更稳定、效率更好，也能避免显式形成逆矩阵。只有确实需要逆矩阵本身时才考虑 `inv(A)`。

### 29. 如何判断矩阵是否方阵、是否包含有限值？
```matlab
isSquare = size(A,1) == size(A,2);
allFinite = all(isfinite(A(:)));
```

### 30. 逻辑索引如何筛选数据？
```matlab
x = [2 8 3 10];
selected = x(x > 5);
x(x < 0) = 0;
```
注意逻辑掩码与被索引数组尺寸是否一致。

## 四、运算符、流程控制与向量化（31–40）

### 31. 常见关系运算符有哪些？
`==`、`~=`、`<`、`<=`、`>`、`>=`。比较结果通常是 logical 数组。

### 32. `&&` 与 `&` 有什么区别？
`&&` 用于标量逻辑表达式并具有短路行为；`&` 可逐元素比较逻辑数组。类似地，`||` 与 `|` 也不同。

### 33. `if/elseif/else` 如何使用？
```matlab
if temperature > 80
    state = "hot";
elseif temperature > 40
    state = "warm";
else
    state = "normal";
end
```

### 34. `for` 循环如何遍历数组？
```matlab
x = [10 20 30];
for value = x
    disp(value);
end
```
MATLAB 的 `for value = A` 按列迭代矩阵。

### 35. `while` 循环要注意什么？
循环条件必须能最终变为假，或通过明确的退出条件终止；防止计数器不更新造成死循环。

### 36. `break` 和 `continue` 的区别？
`break` 退出当前循环；`continue` 跳过本次循环剩余语句并进入下一次迭代。

### 37. 什么是向量化？
用数组运算替代逐元素循环，例如 `y = x.^2 + 2*x + 1`。向量化通常更简洁，但应优先保证清晰与正确。

### 38. 何时不必强行向量化？
复杂状态机、递推算法、顺序依赖逻辑，或向量化会产生巨大临时数组时，循环可能更易读且内存更友好。

### 39. 如何预分配数组？
```matlab
N = 1000;
y = zeros(1,N);
for k = 1:N
    y(k) = k*k;
end
```
预分配可减少数组反复扩容的开销。

### 40. 如何测量代码运行时间？
```matlab
tic;
result = sum(rand(1,1e6));
elapsed = toc;
```
微小代码段建议用 `timeit`（适用版本支持时）进行更可靠的重复测量。

## 五、脚本、函数与调试（41–50）

### 41. 函数文件的基本结构是什么？
```matlab
function y = squareValue(x)
    y = x.^2;
end
```
主函数名称通常应与文件名保持一致。

### 42. 多输入和多输出函数如何定义？
```matlab
function [m, s] = basicStats(x)
    m = mean(x);
    s = std(x);
end
```
调用方可以只接收需要的输出。

### 43. 局部变量和全局变量有什么区别？
函数局部变量有独立作用域；`global` 会引入共享状态，增加耦合和测试难度。一般优先通过参数传递数据。

### 44. 如何设置默认参数？
根据项目版本和接口设计显式检查 `nargin`，或使用 `arguments` 块（需要支持该语法的版本）。不要假设所有旧版本都支持新语法。

### 45. 如何检查输入参数？
检查数量、类型、尺寸、范围和单位；无效输入应给出明确错误，而不是悄悄继续计算。

### 46. 如何抛出错误或警告？
```matlab
if any(~isfinite(x(:)))
    error('Input must contain only finite values.');
end
warning('Using fallback configuration.');
```

### 47. 如何使用断点调试？
在编辑器行号处设置断点，运行代码后逐步执行并检查变量；命令行也可使用 `dbstop`、`dbstep`、`dbquit`。

### 48. 如何定位同名函数冲突？
```matlab
which mean -all
path
```
避免自定义文件与内置函数同名；必要时整理搜索路径。

### 49. 为什么要把一个大脚本拆成函数？
有助于复用、隔离状态、独立测试、明确输入输出，并减少修改某段逻辑时的连锁影响。

### 50. 如何写可维护的函数？
使用明确的名称和参数；注明单位、输入约束、输出含义；控制副作用；为边界情况和异常输入编写测试。

## 六、数据导入、整理与统计（51–60）

### 51. 如何保存和加载 MAT 文件？
```matlab
save('experiment.mat','x','y');
S = load('experiment.mat');
```
使用结构体接收 `load` 的结果，可减少变量覆盖风险。

### 52. 如何读取文本或 CSV？
可使用 `readmatrix`、`readtable` 或 `textscan`，选择取决于数据是否含表头、混合类型和格式要求；旧版本函数支持情况需核对。

### 53. table 适合什么场景？
适合列具有不同类型、并带有变量名的数据，例如时间戳、传感器编号、测量值。矩阵更适合同类型数值运算。

### 54. 如何处理重复数据？
根据业务主键定义重复规则，再使用 `unique` 或 table 相关函数。先确定保留第一条、最后一条还是聚合，不能只按整行相同判断。

### 55. 如何排序和查找极值？
```matlab
sorted = sort(x);
[mx, idxMax] = max(x);
[mn, idxMin] = min(x);
```
含 NaN 时需明确采用何种缺失值处理策略。

### 56. `mean`、`median`、`std` 分别表示什么？
均值、中位数、标准差。均值对极端值更敏感；标准差的归一化方式应按统计假设选择。

### 57. 如何按条件统计数据？
```matlab
count = nnz(x > threshold);
ratio = mean(x > threshold);
```
逻辑值的均值可表示满足条件的比例（前提是数据非空且条件定义明确）。

### 58. 如何处理 NaN？
使用 `isnan` 找到缺失项；是否忽略缺失值应显式决定，并记录删除或填补策略。不同函数、版本对缺失值的默认行为可能不同。

### 59. 如何做简单线性拟合？
可使用 `polyfit(x,y,1)` 得到一次多项式系数；使用前应检查样本数量、数据有效性和模型适用性。

### 60. 数据处理为什么要保留原始数据？
保留原始数据可以追溯、复现并比较清洗前后结果。建议将原始输入、处理参数、处理后数据和分析报告分开保存。

## 七、绘图与结果表达（61–70）

### 61. 如何画二维曲线？
```matlab
x = linspace(0,2*pi,500);
y = sin(x);
plot(x,y);
grid on;
xlabel('Time (s)');
ylabel('Amplitude');
title('Sine wave');
```

### 62. 如何在同一坐标轴画多条曲线？
使用 `hold on` 后绘图，完成后使用 `hold off`；或将多组数据传给支持多曲线的绘图函数。

### 63. 如何添加图例？
使用 `legend('Signal A','Signal B')`，标签应与曲线顺序对应。多曲线时建议显式设置线型或颜色，提升可读性。

### 64. 如何创建多个子图？
使用 `subplot` 或较新版本支持的 `tiledlayout` 与 `nexttile`。旧版本兼容性要求较高时优先核对目标版本支持情况。

### 65. 如何画散点图和柱状图？
使用 `scatter(x,y)` 表示样本间关系；使用 `bar(values)` 比较类别数值。图表类型应匹配数据含义。

### 66. 如何画直方图？
`histogram(x)` 展示数据分布。分箱宽度和分箱边界会影响视觉判断，比较不同数据集时应统一设置。

### 67. 如何画三维曲面？
常用 `meshgrid` 生成网格，再用 `surf(X,Y,Z)` 或 `mesh(X,Y,Z)` 绘图。要确保 X、Y、Z 的尺寸匹配。

### 68. 如何保存图形？
可使用 `saveas` 或 `exportgraphics`（依 MATLAB 版本而定）。报告用图应设置合适的尺寸、分辨率和字体。

### 69. 为什么图形必须标注单位？
没有单位的坐标轴可能导致错误解释。标题、坐标轴、图例应明确说明信号名称、单位、时间范围和必要的处理步骤。

### 70. 如何避免误导性图表？
显示合理的坐标范围和采样信息；不要隐藏关键数据或混用单位；在平滑、滤波、截断坐标轴后明确说明处理方式。

## 八、数值计算与信号处理（71–80）

### 71. 如何求解线性方程组？
```matlab
A = [3 1; 1 2];
b = [9; 8];
x = A\b;
```
求解前要检查方程组是否合理、是否病态，以及解是否符合物理约束。

### 72. 什么是矩阵条件数？
条件数描述输入扰动对求解结果的潜在放大程度。可使用 `cond(A)` 进行诊断；条件数大意味着数值结果可能对误差敏感。

### 73. 如何求特征值和特征向量？
使用 `eig(A)`。解释结果前应确认矩阵定义、数值误差和特征向量归一化等约定。

### 74. 如何做数值积分？
对离散数据可考虑 `trapz(x,y)`；对函数积分可考虑 `integral`（依版本而定）。采样间隔、单位和积分区间都应明确。

### 75. 如何计算离散信号的 FFT？
```matlab
N = numel(x);
X = fft(x);
f = (0:N-1) * Fs/N;
```
实际使用时需明确采样率 Fs、单边/双边频谱、幅值归一化和窗函数影响。

### 76. 为什么频谱会出现泄漏？
有限长度截断等效于乘窗，频率不落在频率栅格上时能量会扩散。可根据分析目标选择窗函数并说明幅值校正方式。

### 77. 采样率和奈奎斯特频率是什么关系？
采样率为 Fs 时，理想情况下可表示的最高频率上限为 Fs/2；采样前需考虑抗混叠滤波，避免高频折叠到低频。

### 78. 如何对传感器数据进行平滑？
可以评估移动平均、中值滤波或低通滤波，但滤波器选择应依据噪声类型、延迟预算、信号带宽和异常值特征。

### 79. 如何实现简单的一阶低通滤波？
```matlab
alpha = 0.1;
y = zeros(size(x));
if ~isempty(x)
    y(1) = x(1);
    for k = 2:numel(x)
        y(k) = alpha*x(k) + (1-alpha)*y(k-1);
    end
end
```
这里 alpha 是离散滤波系数，不是通用截止频率；实际设计应由采样周期与目标截止频率推导。

### 80. 如何验证滤波器没有破坏有效信号？
比较滤波前后波形、频谱、延迟、峰值和稳态误差；使用已知测试信号与边界数据，不能只凭曲线“看起来更平滑”判断。

## 九、工程实践、性能与测试（81–90）

### 81. 为什么要把数据、算法和绘图分开？
分层能让算法脱离界面独立测试，减少重复代码，并方便未来把同一算法用于批处理、脚本或代码生成。

### 82. 如何组织一个 MATLAB 小项目？
建议分为 `src/`（算法函数）、`tests/`（测试）、`data/`（输入数据）、`results/`（输出结果）和 `README.md`（运行说明）。避免将临时文件混入源码。

### 83. 如何编写单元测试？
给定输入与预期输出，覆盖正常值、边界值和非法输入；使用容差比较浮点结果。支持的版本可采用 MATLAB 单元测试框架。

### 84. 如何检查数组尺寸？
用 `size`、`numel`、`isempty` 等检查，并在函数入口处验证维度约束。不要依赖隐式扩展碰巧产生预期结果。

### 85. 什么是隐式扩展？
在支持该功能的 MATLAB 版本中，兼容维度为 1 的数组可以参与逐元素运算，例如列向量与行向量运算生成矩阵。需要兼容旧版本时，应检查版本或显式使用 `bsxfun` 等方案。

### 86. 如何分析性能瓶颈？
先使用 profiler 找出热点，再优化最耗时的部分；不要凭猜测重写代码。性能测试应使用代表性数据并重复测量。

### 87. 为什么避免在循环里不断拼接数组？
反复扩展数组可能产生额外内存分配。已知长度时预分配；长度未知时可考虑分块存储或合适的数据结构。

### 88. 如何减少内存占用？
避免不必要的数组副本和大尺寸临时矩阵；只保留需要的数据；在精度允许时评估 `single`；分块处理大型数据。

### 89. 如何记录实验结果？
保存输入、参数、随机种子、软件版本、运行时间和结果摘要。重要实验还应保存脚本版本或 Git commit，确保可追溯。

### 90. 如何设计边界测试？
覆盖空数组、单元素、极大/极小值、NaN/Inf、尺寸不匹配、重复值和阈值边界；依据函数契约确定每种输入的预期行为。

## 十、面向嵌入式与算法验证（91–100）

### 91. MATLAB 如何作为 C 算法的参考模型？
先用 MATLAB 明确数学定义和输入输出，再建立固定测试向量，最后与 C 版本逐样本比较；需统一单位、数据类型、初始状态和舍入规则。

### 92. 浮点算法与定点算法比较时要看什么？
量化误差、溢出、饱和/回绕策略、舍入方式、动态范围和计算资源。MATLAB 双精度结果不应直接当作定点实现的逐位预期值。

### 93. 如何构造算法测试向量？
至少包括典型输入、边界输入、阶跃、斜坡、正弦、噪声、异常值和长时间运行场景；记录每组测试的目的与预期。

### 94. 如何定义算法误差指标？
常用最大绝对误差、均方根误差（RMSE）和相对误差。接近零的参考值会使相对误差失真，因此应同时考虑绝对误差。

### 95. 如何验证查表与插值算法？
测试表格端点、表内节点、节点之间、越界输入、重复节点和非单调输入；明确越界策略是钳位、外推还是报错。

### 96. 如何验证 Kalman 滤波器？
检查状态与协方差维度、初始状态、过程噪声和测量噪声设定；使用已知轨迹、噪声数据和异常测量比较估计误差及收敛行为。

### 97. 如何验证控制系统响应？
检查阶跃响应、稳定时间、超调量、稳态误差和输入限制；模型参数、采样周期、初始条件必须记录。工具箱函数应标注依赖。

### 98. 如何从 MATLAB 算法走向代码生成？
先确认目标函数和数据类型符合代码生成限制，再检查动态内存、可变尺寸、工具箱支持和目标编译器；生成代码后仍须在目标环境测试。

### 99. 如何与 Simulink 配合？
把算法函数作为可验证单元，再根据需要构建模型、配置采样时间、输入输出接口和测试场景。连续系统与离散系统的时间语义不能混淆。

### 100. 一个 MATLAB 工程练习怎样算完成？
应至少具备：问题定义、输入数据、算法实现、运行说明、自动化或可重复测试、结果可视化、误差分析、版本记录，以及对适用范围和限制的说明。
